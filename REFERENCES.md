Read for ideas only, no code taken: [Boring Notch](https://github.com/TheBoredTeam/boring.notch) and NotchDrop, which both put a file shelf in the notch.

Everything else in this repo was written for this project. The interface sounds are generated by `scripts/make_sounds.py` and the grain texture by a few lines of Python; nothing was downloaded or sampled. `App/RotationBridge` is original code (not copied) that uses the same generic, widely-documented Objective-C category technique the open-source Rotator app (github.com/B-HS/rotator) also uses for the same purpose. The pitch detector follows the published YIN method (de Cheveigné and Kawahara, 2002).

Apple frameworks used by the app: SwiftUI, AppKit, AVFoundation (voice, sounds, microphone), Speech (hold-to-talk), EventKit (reminders), Security (Keychain), and AppleScript through NSAppleScript (the front browser tab, and Notes).
